# miniproj1

Este projeto faz parte da tarefa 2.2 de Programação Web Avançada, do Mestrado de Engenharia Informática e Tecnologia Web.

## IDE Recomendado

[VS Code](https://code.visualstudio.com/)

## Setup Inicial

```sh
npm install
```

### Compilar e Ver Projeto em Desenvolvimento

```sh
npm run dev
```

### Compilar e Minificar para Produção

```sh
npm run build
```
